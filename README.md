# Сайт SELF.KG — SelfVisa & SelfAcademy

Сайт на трёх языках (RU / KG / EN) с админ-панелью по адресу **self.kg/admin**.
Все заявки с сайта открываются в WhatsApp на номер из настроек.

## Что внутри

| Папка / файл | Что это |
|---|---|
| `content/` | Весь текст сайта. Его меняет админ-панель — руками трогать не нужно |
| `content/visa/ru, ky, en` | Страницы виз (США, Европа, Китай, Корея, Япония, Канада) |
| `content/study/ru, ky, en` | Страницы учёбы (Корея, США, Франция, Италия, Малайзия, Китай) |
| `content/home/` | Главная страница и тексты интерфейса для каждого языка |
| `content/settings/site.json` | Телефон, WhatsApp, Instagram, адрес карты, цвета, логотип |
| `admin/` | Админ-панель (Sveltia CMS) |
| `assets/` | Стили, шрифты, флаги, скрипты |
| `uploads/` | Фото, загруженные через админку |
| `build.js` | Собирает готовый сайт в папку `dist/` |

## Запуск на self.kg (один раз, ~30 минут)

### 1. GitHub — хранилище сайта
1. Зарегистрируйтесь на [github.com](https://github.com).
2. **New repository** → имя `selfkg` → Private → Create.
3. **Add file → Upload files** → перетащите всё содержимое этой папки (не саму папку) → **Commit changes**.
4. Откройте файл `admin/config.yml` (карандаш ✏️) и замените `YOUR-GITHUB-USERNAME` на ваш логин GitHub. Сохраните.

### 2. Netlify — бесплатный хостинг
1. Зайдите на [netlify.com](https://www.netlify.com) → **Sign up with GitHub**.
2. **Add new site → Import an existing project → GitHub** → выберите `selfkg`.
3. Настройки подтянутся сами (`netlify.toml`). Нажмите **Deploy**. Через минуту сайт откроется на временном адресе `что-то.netlify.app`.

### 3. Домен self.kg
1. В Netlify: **Domain management → Add a domain** → `self.kg`.
2. У регистратора домена в настройках DNS:
   - запись **A** для `self.kg` → `75.2.60.5`
   - запись **CNAME** для `www` → ваш адрес `что-то.netlify.app`
   (или переключите NS-серверы на Netlify DNS — Netlify покажет, какие).
3. HTTPS включится автоматически в течение часа.

### 4. Вход в админку
1. На GitHub: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
   - Repository access: только `selfkg`
   - Permissions → **Contents: Read and write**
2. Откройте **self.kg/admin** → **Sign in with token** → вставьте токен.

Каждого сотрудника, который будет редактировать сайт, добавьте в репозиторий (**Settings → Collaborators**) — он создаёт свой токен так же.

## Как редактировать

1. Открываете **self.kg/admin**, выбираете раздел: Визы, Учёба, Главная или Настройки.
2. Меняете текст — в странах переключатель языков RU / KY / EN сверху редактора.
3. Нажимаете **Сохранить**. Через 1–2 минуты изменения появятся на сайте.

**Добавить новую страну:** в разделе «Визы» или «Учёба» → **Новая** → заполните поле «Адрес страницы» латиницей (например `uk`) и тексты на трёх языках. Страна сама появится в меню, на главной и в форме заявки.

**Скрыть страницу:** снимите галочку «Опубликовано».

## Что заполнить перед запуском

- [ ] **Настройки → телефон и номер WhatsApp** (сейчас стоит `+996 000 000 000` — заявки не дойдут, пока не заменить)
- [ ] Часы работы и адрес (Главная → для каждого языка)
- [ ] Email (если нужен на сайте)
- [ ] Логотип и фирменные цвета (Настройки)
- [ ] Фото в шапку страниц стран (необязательно — без фото показывается флаг)
- [ ] Настоящие отзывы клиентов (Главная → Отзывы) — блок появится автоматически
- [ ] Проверить цены/сроки и кыргызские тексты носителем языка

```bash
npm install
npm run build      # сайт в dist/
npx serve dist     # открыть http://localhost:3000
```
